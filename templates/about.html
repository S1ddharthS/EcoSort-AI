{{ icon("info") }} About EcoSort AI

Simple answers for a messy problem

EcoSort AI is a college project that pairs a small computer-vision model with plain-language recycling guidance.

{{ icon("shield") }}

Only measured results are shown. Nothing on this page is estimated or made up.

{{ icon("recycle") }}

The problem

Recycling labels are inconsistent and local rules are hard to remember. One wrong item can contaminate a whole bin, while useful materials end up in landfill because people aren't sure what to do.

{{ icon("sparkles") }}

Our approach

Take one photo. The model sorts it into one of six common categories. If it isn't confident, it says so instead of guessing. Confident results come with preparation steps, bin guidance and a Grad-CAM explanation.

What the model learned from

{% if metrics and metrics.dataset.class_totals %}

{{ metrics.dataset.total_images }} real images were used in total, split about 70% training, 15% validation and 15% test. Data was de-duplicated and checked for corrupt files before splitting.

TrashNet supplies plastic, paper, cardboard, glass and metal. Its sixth “trash” class was deliberately dropped because EcoSort does not have a mixed-trash category.

Organic images come from the biological subset of a public 12-class garbage classification dataset. These are food/food-waste photos, so garden waste is less represented.

{{ icon("sparkles") }} Under the hood

How a photo becomes guidance

  1. 1{{ icon("camera") }}

    Capture

    The browser sends a JPEG frame or an uploaded file (max 5 MB).

  2. 2{{ icon("image") }}

    Preprocess

    OpenCV resizes to 224 × 224, converts BGR to RGB and scales pixels to 0–1.

  3. 3{{ icon("scan") }}

    Classify

    MobileNetV2 transfer learning returns a probability for each of six classes.

  4. 4{{ icon("leaf") }}

    Explain

    Grad-CAM highlights influential pixels. The result is stored with its guidance.

{{ icon("alert") }} Honest limits

What EcoSort can't do

These limitations are part of the project, not hidden fine print.

{{ icon("alert") }}

Only six classes

Batteries, clothes, electronics, mixed piles and unknown items are outside the model's vocabulary.

{{ icon("box") }}

One item at a time

The model looks at the whole photo. A pile of mixed waste can confuse it, and hidden materials are invisible.

{{ icon("camera") }}

Photos matter

Low light, blur, clutter and unusual angles reduce confidence. The model learned mostly from studio-style object photos.

{{ icon("apple") }}

Organic is food-led

The organic class was trained on food/food-waste images. Garden waste and compost mixes may be less reliable.

{{ icon("map-pin") }}

Rules are local

Bin colours and accepted materials vary by city and country. Guidance here is general and marked where it varies.

{{ icon("info") }}

Confidence is not certainty

A softmax probability reflects the model's training, not a guarantee. Low-confidence results are not given a bin recommendation.

{{ icon("lock") }}

Privacy. Images are stored locally in this app's SQLite database folder only. There is no cloud account and no external API call for predictions.
